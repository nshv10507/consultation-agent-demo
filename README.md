# 高齢者向けAI相談エージェント

## 概要

創立50周年記念式典でのデモンストレーション用 MVP（最小限の実行可能製品）です。

高齢者やIT低リテラシー層が、詐欺メール、操作不安、心理的な不安などに直面した時に、**AIが24/7でサポート**するシステムです。

### 特徴
- 🤖 **テキストベース相談**: シンプルで親しみやすいインターフェース
- 🚨 **詐欺警告**: 詐欺メールを検知して警告
- 📱 **操作ガイド**: 基本的なスマートフォン/パソコン操作を説明
- 💪 **安心感醸成**: 不安な気持ちに共感し、励まし
- ⚡ **高速応答**: 2秒以内に返答

## インストール & 実行

### 1. ローカル環境での実行

#### 前提条件
- Python 3.9 以上
- pip がインストールされていること

#### セットアップ手順

```bash
# リポジトリをクローン
git clone https://github.com/[your-user]/consultation-agent-demo.git
cd consultation-agent-demo

# 仮想環境を作成
python -m venv venv

# 仮想環境を有効化
# Windows の場合
venv\Scripts\activate
# macOS / Linux の場合
source venv/bin/activate

# 依存パッケージをインストール
pip install -r requirements.txt
```

#### アプリを実行

```bash
streamlit run app.py
```

ブラウザが自動で開き、`http://localhost:8501` でアプリが起動します。

### 2. Streamlit Cloud でのデプロイ

#### デプロイ手順

1. **GitHub にプッシュ**
   ```bash
   git add .
   git commit -m "Initial commit: Consultation agent MVP"
   git push origin main
   ```

2. **Streamlit Cloud にアクセス**
   - https://streamlit.io/cloud
   - GitHub アカウントでログイン

3. **新規アプリ作成**
   - 「New app」をクリック
   - リポジトリを選択
   - `app.py` を指定
   - デプロイ開始

4. **アクセス**
   - デプロイ完了後、`https://[app-name].streamlit.app` でアクセス可能

## 使い方

### デモシナリオ 1: 詐欺警告

```
【入力】Amazonからメールが来てクリックするように書いてある

【期待出力】
🚨 【警告】これは詐欺メール（フィッシング）の可能性が非常に高いです。

❌ やってはいけないこと：
  • そのメール内のリンクをクリックしない
  • 個人情報（パスワード、電話番号など）を入力しない
  
✅ やるべきこと：
  • そのメールは削除してください
  • 本物の公式サイトから直接ログインしてください
  • 不安なら家族や友人に相談してください
```

### デモシナリオ 2: 操作ガイド

```
【入力】Wi-Fiに繋がらない

【期待出力】
分かりました。以下の手順をお試しください。

📱 【Wi-Fi接続手順】
1️⃣ スマートフォンの『設定』アプリを開く
2️⃣ 『Wi-Fi』をタップ
3️⃣ 接続したい自分のWi-Fi名を選ぶ
4️⃣ パスワードを入力して『接続』をタップ
```

### デモシナリオ 3: 不安払拭

```
【入力】ボタン間違えて押したら壊れてしまうかも

【期待出力】
大丈夫ですよ。安心してください。

✅ スマートフォンやパソコンについて：
  • ボタンを少し押しただけでは、まず壊れません
  • 間違えて何かしても、ほぼ大丈夫です
  • 不安なことは、ためらわずに周りの人に聞いてください
```

## 設定方法

### Streamlit Cloud での環境変数設定（オプション）

LLM API を使用する場合（将来の拡張版では）:

1. Streamlit Cloud のアプリ設定を開く
2. 「Secrets」タブをクリック
3. 以下を追加:
   ```toml
   OPENAI_API_KEY = "sk-..."
   ```

### ローカル環境での .env 設定

```bash
# .env ファイルを作成
echo 'OPENAI_API_KEY=sk-...' > .env
```

**⚠️ 注意**: `.env` は絶対に GitHub にコミットしないでください。`.gitignore` に追加されています。

## トラブルシューティング

### Q: アプリが起動しない
**A**: 以下を確認してください
```bash
# Python バージョン確認
python --version  # 3.9+ 必須

# 依存パッケージ再インストール
pip install -r requirements.txt --force-reinstall

# ローカル実行テスト
streamlit run app.py
```

### Q: scenarios.json が読み込めない
**A**: ファイルが同じディレクトリに存在することを確認
```bash
ls scenarios.json  # ファイルが存在するか確認
```

### Q: 応答が遅い
**A**: 以下を確認
- インターネット接続を確認
- Streamlit Cloud のステータスページを確認
- ローカルで実行して比較

### Q: Streamlit Cloud でのデプロイが失敗する
**A**: 以下を確認
- `requirements.txt` が正しいか確認
- GitHub リポジトリに全ファイルがアップロードされているか確認
- Streamlit Cloud のデプロイログを確認

## セキュリティ

### API キー管理
- ✅ `.env` は `.gitignore` に指定
- ✅ Streamlit Cloud の Secrets を使用
- ✅ GitHub リポジトリは public OK（秘密情報なし）

### データプライバシー
- ⚠️ チャット履歴はメモリのみ（サーバーに保存されない）
- ⚠️ 本番化時は SQLite での永続化が必要
